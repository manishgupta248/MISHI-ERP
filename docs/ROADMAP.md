# MISHI-ERP — Roadmap

## Phase 1 — Foundation
Project structure, environment, Django foundation, documentation and Git.

## Phase 2 — Core Platform
Common models, utilities, authentication, permissions and reusable services.

## Phase 3 — ERP Applications
Individual business modules developed as separate Django applications.

## Phase 4 — Events and Automation
Events, scheduled tasks and workflow automation.

## Phase 5 — Telegram Integration
Telegram bot and messaging interface.

## Phase 6 — AI / LLM Layer
LLM integration, agent capabilities and controlled tool execution.

## Phase 7 — Agentic ERP
Integration of ERP functions, events, automation and AI agents.

## Phase 8 — Hardening
Security, testing, backup, recovery, performance and deployment readiness.
